## What gSpot is

Single-user golf app for CSJ: enter scores hole by hole, get a World Handicap System (WHS) Handicap Index per England Golf rules, track rounds and stats. Plain HTML/CSS/JS PWA, no framework, no build step, data in localStorage, synced to a private GitHub repo. Modelled on VPAR's scorecard (all holes on one scrolling screen, front/back nine totals, round total), not VPAR's colours.

- Live: https://stoff73.github.io/gspot/ (GitHub Pages from `main` of github.com/Stoff73/gspot). Push to main = deploy in about a minute.
- Data: `state.json` in the private repo github.com/Stoff73/gspot-data, written by the app through GitHub's contents API with a fine-grained token CSJ pastes into the app. Never ask for or handle that token.
- Spec: `docs/superpowers/specs/2026-09-08-golf-handicap-pwa-design.md` (kept current, including the sync rework).
- Rules source: `docs/handi.md` (CSJ's WHS notes). Engine also checked against R&A Rule 5 text, the Golf RSA 2024 training deck and England Golf April-2024 guidance.

## State of play

Everything below is built, tested in Chrome at phone width, committed and deployed. Working tree is clean except this handover.

- **Scorecard**: one scrolling list, per hole: par, SI, yards, shots received, score stepper (grey par until tapped), putts stepper, FIR (hidden on par 3) and GIR toggles, Stableford points, "capped to N" marker. Front 9 / Back 9 / Round totals. Save only when every hole is entered. Date field defaults to today and can be backdated.
- **Handicap engine** (all in `handicap.js`, all covered by the test file): net double bogey (par+5 before an Index exists), Score Differential 113/Slope×(AGS−CR−PCC), Rule 5.2a table for 3–20 scores, 54-hole minimum, max 54.0, Low Index over 365 days once 20 scores exist, soft cap 3.0 / hard cap 5.0, ESR on the unrounded differential applied to the last 20, Course Handicap with CR−Par, Playing Handicap from the unrounded Course Handicap. 9-hole rounds: differential from the nine's own CR/Slope (optional per tee, fallback CR/2 flagged "est."), combined with an expected 9-hole differential approximated as 0.51×Index+1.36 (fitted to the two official worked examples; the real table is unpublished). 9-hole Course Handicap = Index/2×Slope9/113+(CR9−Par9), shots by SI rank within the nine.
- **PCC** is a manual per-round field (single-user app cannot compute a field's PCC).
- **Courses**: Westerham, Woldingham, Poult Wood (18 and the 9-hole played twice), Darenth Valley, Wildernesse, Nizels, Surrey National, Royal Blackheath. Men's tees only. Darenth Valley has no scorecard in the API: card from golfify.io, ratings from 18birdies.com, id `manual-darenth-valley`. CSJ was told to check those ratings against the club card.
- **In-app course search** uses the UK Golf Course Data API on RapidAPI; CSJ pastes their RapidAPI key in the Courses tab. Free plan is rate-limited per minute. Key is not in any file.
- **Sync**: Courses tab → Sync card → GitHub token → Sync now. Pull on open/visibility, push 1.5 s after a change, retry on `online`. Pushes wait for the first pull so a new device adopts the server copy. Last write wins with a 409 retry. Tested against a local mock of the contents API, not yet against real GitHub with a token (CSJ has to create the token).

## Gotchas

- `app.js` `render()` rebuilds the whole view; click handlers restore scroll with `keep()`. Scripted tests must re-query elements after each click.
- `save()` writes localStorage on every render but only schedules a push if the synced subset (`courses, rounds, settings, draft`) changed; `S.tab` is excluded on purpose.
- Service worker is network-first, so deploys land on next open without a cache bump.
- Old rounds saved before the 9-hole rework lack `rank`/`nHoles`; code falls back to `si`/18. CSJ had no real rounds at that point, so no migration exists.
- Ponytail mode is active in this repo's sessions: laziest working solution, mark deliberate shortcuts with `// ponytail:` comments. Two exist (expected 9-hole differential fit; network-first SW).
- Never enter, store or print CSJ's tokens or keys. RapidAPI key and GitHub token go from CSJ straight into the app on their device.
